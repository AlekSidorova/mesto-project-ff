# Mesto

![Project Screenshot](/src/images/screenshot__main.png)

Учебный проект, выполненный в рамках обучения
и доработанный для портфолио.

## Описание
Mesto — учебное веб-приложение, в котором реализована работа с DOM,
формами и API: редактирование профиля, управление карточками и лайками
без перезагрузки страницы.

## Демо
Посмотреть проект можно по следующей ссылке: [Mesto Project Demo](https://aleksidorova.github.io/mesto-project-ff/)

## Функциональность
- Загрузка аватара пользователя
- Редактирование информации о пользователе
- Добавление и удаление карточек
- Лайки для карточек
- Динамическое обновление интерфейса без перезагрузки страницы

## Используемые технологии
- HTML
- CSS
- JavaScript
- API
- Git/GitHub
